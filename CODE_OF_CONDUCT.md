# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be decent. Assume good faith, critique code rather than people, and accept that
maintainer time is finite and unpaid.

Report unacceptable behaviour through
[GitHub Security Advisories](../../security/advisories/new) or a direct message to the
maintainer. Reports are handled confidentially.
